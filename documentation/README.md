## 🏗️ About Axtrizen AI

**Axtrizen AI** is a desktop-native multi-agent orchestration platform that enables humans to assemble teams of AI agents, assign them software projects, and watch them autonomously execute the full Software Development Lifecycle (SDLC).

**Tech Stack:** Rust + Tauri 2.0 + React 18 + SQLite + OpenClaw Gateway

**Version:** 0.1.0-alpha | **Author:** Akash Ranjan
